# Individual 16×16 PNGs

6,653 accepted Small Seal glyphs, each a transparent 16×16-pixel RGBA PNG rendered from the production Regular400 font. 4,675 pending glyphs have no individual file. The separate 45 PNG grids continue to show every block position.

Files are named `U3D000.png` and so on. `manifest.json` binds each bitmap to its accepted geometry, source, render settings and PNG fingerprint. Unchanged glyph bitmaps are reused across checkpoints.
