# Individual 16×16 PNGs

All 11,328 Unicode 18 Small Seal codepoints, U+3D000–U+3FC3F, have a transparent 16×16-pixel RGBA PNG rendered from the production Regular 400 font. The separate 45 square PNG sheets display the same complete repertoire in 16×16 grids of cells.

Files are named `U3D000.png` through `U3FC3F.png`. `manifest.json` binds each bitmap to its accepted geometry, source, render settings and PNG fingerprint. Unchanged glyph bitmaps are reused on subsequent exports.
