# Sealie

Built outputs for the Panorama Gothic Small Seal font for Unicode 18.

Current checkpoint: **1,113 of 11,328 glyphs reviewed at Regular 400**. Work continues across the full Small Seal block, U+3D000–U+3FC3F, in batches of 64.

- [Variable TTF, weights 300–700](https://github.com/iebb/sealie/releases/download/checkpoint-001113/PanoramaGothicSealIndividualVariable.ttf)
- [Variable WOFF](fonts/PanoramaGothicSealIndividualVariable.woff)
- [Regular TTF](https://github.com/iebb/sealie/releases/download/checkpoint-001113/PanoramaGothicSealIndividual-Regular.ttf)
- [Regular WOFF](fonts/PanoramaGothicSealIndividual-Regular.woff)
- [Weight preview](previews/weight-slider.html)
- [Coverage and validation](reports/coverage.json)

All five named-weight TTFs are in the [checkpoint release](https://github.com/iebb/sealie/releases/tag/checkpoint-001113). WOFF files stay in [fonts](fonts/) for local browser previews. The glyphs use a shared rounded monoline construction with proportional sizing and a 1024-unit advance. The original 128 outlines and metrics remain unchanged. All five named weights pass compiled size checks; their optical review continues. This is an incomplete development font.
