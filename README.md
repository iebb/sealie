# Sealie

Built outputs for the Panorama Gothic Small Seal font for Unicode 18.

Current checkpoint: **656 of 11,328 glyphs reviewed at Regular 400**. Work continues across the full Small Seal block, U+3D000–U+3FC3F, in batches of 64.

- [Variable TTF, weights 300–700](fonts/PanoramaGothicSealIndividualVariable.ttf)
- [Variable WOFF](fonts/PanoramaGothicSealIndividualVariable.woff)
- [Regular TTF](fonts/PanoramaGothicSealIndividual-Regular.ttf)
- [Regular WOFF](fonts/PanoramaGothicSealIndividual-Regular.woff)
- [Weight preview](previews/weight-slider.html)
- [Coverage and validation](reports/coverage.json)

Named weight TTFs are also in [fonts](fonts/). The glyphs use a shared rounded monoline construction with proportional sizing and a 1024-unit advance. The original 128 outlines and metrics remain unchanged. All five named weights pass compiled size checks; their optical review continues. This is an incomplete development font.

![Current glyph preview](previews/glyphs.png)

This repository contains built font files, previews, licenses, and output reports. Drawing sources, drafts, and build tooling stay in the working repository. Paths inside diagnostic reports identify that build workspace.
