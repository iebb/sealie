# Small Seal PNG grids

Each square PNG has 16 columns × 16 rows of square cells. Each cell is labeled with its Unicode18 codepoint. The shared Regular400 font supplies the reviewed glyphs. Gray cells labeled **pending** have no completed glyph yet; darker cells in the last sheet fall outside the Small Seal block.

Current coverage: **3,321 of 11,328** glyphs; 8,007 remain pending. All 11,328 codepoint positions appear across these 45 sheets.
